# 当前中英文 LaTeX 压缩包

这个文件夹用于集中保存当前论文的 Overleaf/LaTeX 可编辑版本。

## 文件

- `中文论文_LaTeX_Overleaf_2026-08-31.zip`：只包含中文论文的 LaTeX 工程。上传到 Overleaf 后，将主文件设为 `main.tex`，编译器选择 XeLaTeX。
- `English_Dissertation_LaTeX_Overleaf_2026-08-31.zip`：只包含英文论文的 LaTeX 工程。上传到 Overleaf 后，将主文件设为 `main.tex`，编译器选择 XeLaTeX。
- `中英文合集_LaTeX_Overleaf_2026-08-31.zip`：包含 `zh/main.tex` 和 `en/main.tex` 两个版本，适合一次性备份。上传到 Overleaf 后需要手动选择对应主文件。

## 注意

中文版本使用 Overleaf 较容易支持的 `ctex` Fandol 字体配置，不依赖本机 Windows 字体。
