## 建议查看顺序

1. 先阅读 `游戏工程论文写作要求_MScGEDissertation.pdf`。
2. 打开模板 PDF，对照标题页、目录、章节标题、页边距和附录版式。
3. 优先阅读 `09_完整显示设计与数据讨论论文_2026-08-24` 中的中文 PDF 和完整 Word。
4. 如需了解删改过程，再依次对比 `08`、`07`、`06`、`05` 和更早版本。
