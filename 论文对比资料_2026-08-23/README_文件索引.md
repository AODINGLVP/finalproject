## 建议查看顺序

1. 先阅读 `游戏工程论文写作要求_MScGEDissertation.pdf`。
2. 打开模板 PDF，对照标题页、目录、章节标题、页边距和附录版式。
3. 对比同语言的早期版与当前版，重点查看研究方法、结果、讨论和结论。
4. 英文当前版作为正式论文写作基准；中文当前版用于快速审阅内容与数据含义。
