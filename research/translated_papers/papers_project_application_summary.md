## 1. 大扇出树可视化论文重点

这篇论文研究的问题是：当树中某个节点有大量子节点时，传统节点-连线树会迅速变得拥挤，用户难以浏览和理解。

论文比较了三种界面：

- 传统树形节点-连线布局。
- 带滚动条的列表布局。
- 多列布局。

实验结果显示，多列布局在浏览速度、理解结构和用户偏好方面表现更好。

### 对行为树插件的应用

行为树中的 `Selector` 或 `Sequence` 可能包含很多子节点，例如一个敌人有很多备选行为。传统树布局会导致节点挤在一起。可以借鉴多列布局：

- 当一个节点有很多子节点时，自动分成多列显示。
- 对大分支提供分组和分栏。
- 在 Compact Mode 中减少节点宽度。
- 将“执行顺序”用编号标出，避免多列后顺序不清。

### 可写入毕业设计的点

可以说明：

> 针对行为树中大扇出节点导致的显示拥挤问题，本项目参考多列树可视化方法，将同一父节点下的大量子节点进行分栏布局，以提高树结构的可读性。

## 2. Quilts 大型分层图论文重点

这篇论文研究大型分层图的显示问题。传统流程图或节点-连线图在节点和连接增多后，会出现连线重叠、遮挡和路径难找的问题。

Quilts 使用类似矩阵的方式显示分层图，重点改善路径查找任务。实验显示，在大型图中，Quilts 比节点-连线图和矩阵图更快。

### 对行为树插件的应用

行为树也是一种分层结构，调试时最重要的问题之一是“当前执行路径在哪里”。因此可以借鉴 Quilts 的思路，不一定只依赖完整节点图。

可应用方向：

- 在 Live Debug 中单独显示当前执行路径。
- 对当前路径使用更强的颜色和文字混合编码。
- 对非当前路径弱化显示。
- 对大型树提供一个“路径摘要视图”，只显示从 Root 到当前节点的链条。

### 可写入毕业设计的点

可以说明：

> 大型分层图研究表明，传统节点-连线图在复杂图中路径查找效率下降。因此，本项目在行为树调试中突出显示当前执行路径，以降低开发者理解 NPC 行为的成本。

## 3. 大型网络复杂度管理论文重点

这篇论文讨论大型网络可视化中的复杂度管理。核心问题是：图太大时，全部显示会形成“hairball”，导致用户无法分析。

论文提出和实现了：

- expand-collapse
- hide-show
- hierarchical clustering
- incremental layout
- mental map preservation

其中最重要的是：折叠/展开后，布局不应完全重排，否则用户会失去对图的空间记忆。

### 对行为树插件的应用

这是最适合指导你的“节点折叠”功能的论文。

可应用方向：

- 子树折叠：把一整段行为压缩成一个 summary node。
- 局部展开：只展开当前选中的子树。
- 隐藏非当前执行分支。
- 展开/折叠时保持其他节点位置稳定。
- 用动画过渡减少视觉跳变。

### 可写入毕业设计的点

可以说明：

> 为了解决大型行为树节点过多导致的可读性问题，本项目参考大型网络复杂度管理方法，引入子树折叠和局部展开机制，并尽量保持节点布局稳定，以维护用户的 mental map。

## 综合应用到当前 Godot 行为树插件

结合三篇论文，可以将你的显示优化方向整理成三个功能模块：

### 1. Compact Mode

来源：

- 大 fan-out 树可视化论文
- Quilts 分层图论文

设计：

- 默认节点只显示标题、类型颜色、运行状态。
- 详细信息放到 Inspector 或悬停展开中。
- 减少节点占用空间，提高同屏节点数量。

### 2. Subtree Collapse

来源：

- 大型网络复杂度管理论文

设计：

- 允许折叠某个节点的全部子树。
- 折叠节点显示子节点数量。
- 展开时恢复原布局。
- Live Debug 当前路径自动展开。

### 3. Active Path Focus

来源：

- Quilts 路径查找实验
- node-link 可读性问题

设计：

- Live Debug 中当前执行路径强高亮。
- 非当前分支降低透明度。
- 当前失败的 Decorator 显示原因。
- 可额外显示一条文字路径：`Root > Selector > Attack Left`。

## 推荐实现顺序

1. 先实现 Compact Mode。
2. 再实现子树折叠和展开。
3. 然后增强 Live Debug 当前路径显示。
4. 最后考虑多列布局或路径摘要视图。

## 推荐论文写法

可以在毕业设计中这样描述：

> 传统行为树编辑器通常采用节点-连线图显示结构，但随着节点数量增加，会出现节点拥挤、连线复杂、当前执行路径难以识别等问题。相关可视化研究表明，多列布局、矩阵式分层图、折叠展开和复杂度管理技术可以改善大型层级结构和网络图的可读性。因此，本项目在 Godot 行为树插件中引入紧凑显示、子树折叠和运行时路径高亮，以提升行为树编辑和调试效率。
