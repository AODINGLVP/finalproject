## 摘要对照翻译

| English | 中文 |
| --- | --- |
| Hierarchical structures with large fan-outs are hard to browse and understand. | 具有大扇出的层级结构很难浏览和理解。 |
| In the conventional node-link tree visualization, the screen quickly becomes overcrowded as users open nodes that have too many child nodes to fit in one screen. | 在传统的节点-连线树可视化中，当用户展开包含大量子节点的节点时，屏幕会很快变得拥挤，因为这些子节点无法全部清晰地放入一个屏幕。 |
| To address this problem, we propose two extensions to the conventional node-link tree visualization: a list view with a scrollbar and a multi-column interface. | 为了解决这个问题，作者提出了对传统节点-连线树可视化的两种扩展：带滚动条的列表视图，以及多列界面。 |
| We compared them against the conventional tree visualization interface in a user study. | 作者通过用户研究，将这两种方法与传统树可视化界面进行了比较。 |
| Results show that users are able to browse and understand the tree structure faster with the multi-column interface than the other two interfaces. | 结果表明，使用多列界面时，用户浏览和理解树结构的速度比使用另外两种界面更快。 |
| Overall, they also liked the multi-column better than others. | 总体上，用户也更偏好多列界面。 |

## 研究动机对照翻译

| English | 中文 |
| --- | --- |
| Organizing large hierarchical information using a tree data structure is quite common. | 使用树结构组织大型层级信息非常常见。 |
| As the hierarchical structure grows bigger, it becomes more and more difficult to understand the overall structure and to browse the hierarchy effectively. | 随着层级结构规模变大，用户越来越难理解整体结构，也越来越难有效浏览层级内容。 |
| A particular problem arises when a node has too many children. | 当某个节点拥有过多子节点时，会出现一个特殊问题。 |
| In a conventional tree visualization, opening such a node may require too much screen space and may push other parts of the tree out of view. | 在传统树可视化中，展开这种节点会占用大量屏幕空间，并可能把树的其他部分挤出视野。 |

## 方法对照翻译

| English | 中文 |
| --- | --- |
| The paper compares three interfaces: a traditional tree display, a list view with scrollbar, and a multi-column layout. | 论文比较了三种界面：传统树显示、带滚动条的列表视图、多列布局。 |
| The traditional tree display uses a standard node-link representation. | 传统树显示使用标准的节点-连线表示方式。 |
| The list view reduces screen crowding by placing many children in a scrollable list. | 列表视图通过将大量子节点放入可滚动列表来减少屏幕拥挤。 |
| The multi-column interface arranges children across multiple columns so that more items can be visible at once. | 多列界面把子节点分布到多个列中，使更多项目能够同时可见。 |
| The authors conduct a controlled user study to measure task performance and user preference. | 作者进行了受控用户研究，用于测量任务表现和用户偏好。 |

## 结果对照翻译

| English | 中文 |
| --- | --- |
| Users performed faster with the multi-column interface than with the traditional tree and list interfaces. | 用户使用多列界面完成任务的速度快于传统树界面和列表界面。 |
| The multi-column layout helped users browse, revisit, and understand the topology of trees with large fan-outs. | 多列布局帮助用户更好地浏览、重访并理解大扇出树的拓扑结构。 |
| Users also reported higher preference for the multi-column interface. | 用户主观上也更偏好多列界面。 |
| The results suggest that changing the layout of expanded children can improve readability without abandoning the tree metaphor. | 结果说明，在不放弃树结构隐喻的前提下，改变展开子节点的布局方式可以提高可读性。 |

## 结论对照翻译

| English | 中文 |
| --- | --- |
| Large fan-outs are a major usability problem in tree visualization. | 大扇出是树可视化中的一个主要可用性问题。 |
| Multi-column layout is an effective alternative to the conventional node-link tree when many child nodes must be displayed. | 当需要显示大量子节点时，多列布局是传统节点-连线树的一种有效替代方案。 |
| The paper demonstrates that layout design can be evaluated through controlled user studies. | 论文表明，布局设计可以通过受控用户实验进行评价。 |

## 对本项目的启发

这篇论文非常适合用于支持行为树编辑器的“大树可读性优化”。行为树中的 `Selector` 或 `Sequence` 可能拥有很多子节点，如果全部按传统树形展开，会导致界面横向或纵向拥挤。

可以应用到你的插件中：

- 当某个节点有很多子节点时，自动使用多列布局。
- 对 `Selector` 的大量子行为进行分栏显示。
- 为大规模行为树提供 `Compact Mode`，减少每个节点占用空间。
- 在毕业设计中用用户任务评价布局效果，例如“找到某个节点所需时间”或“理解执行顺序所需时间”。
