## 怎样使用改进后的编辑器

1. 打开 `testgame/testgame/project.godot`，在 Godot 底部打开 `Behavior Tree` 面板。
2. 从树选择器中选择需要编辑的 `.tres` 资源。创建节点时，在画布空白处右键并选择节点类型；工具栏不再放置一排节点创建按钮。
3. 从父节点底部端口连接到子节点顶部端口。同一父节点下的子节点仍按照画布横坐标从左到右执行。
4. 直接拖动节点即可自由调整位置。拖动过程中和拖动结束后都会进行局部避让；非拖动节点使用临时显示偏移，不会因为避让而改写其保存位置。
5. 打开 `Display > Advanced Display`：
   - `Always Curved Edges (Experiment)` 默认关闭，只用于比较曲线效果。
   - `Translucent Cards (Experiment)` 默认关闭，只用于观察后方连线；若文字与背景线条混淆应立即关闭。
   - 连线障碍避让已经删除，不再出现在菜单中；普通、正交和捆绑连线仍可使用。
6. 其他大型树工具仍可独立使用，包括 Compact、Semantic Zoom、Search、Subtree Focus、Collapse、Fisheye、Minimap、Fit、布局和运行时路径显示。

## 怎样运行可玩游戏

1. 运行 `res://scenes/test_game.tscn`。
2. 使用 `A/D` 移动、`W` 跳跃或向上攀爬、`S` 向下攀爬、`J` 或鼠标左键攻击、`Space` 冲刺、`C` 隐身、`T` 暂停/继续 AI、`R` 重置。
3. 玩家显示 `HP INFINITE`。依次击败五名敌人，敌人不会自动复活；击败第五名后出现胜利面板。
4. 要看真实 241 节点敌人的运行路径，在 `Behavior Tree` 面板选择 `res://behavior_trees/arena_tactician_241.tres`，然后在 `Debug` 中开启 `Live Debug` 与 `Active Path Highlight`。

## 停止边界和保留限制

- 第 3 项曾先回退一个持续高负载超过五分钟的全画布绕线候选。后续诊断又确认轻量局部绕线在缓存失效时仍使 121、241、364 节点树的整批路线重算分别增加约 19、37、47 倍。用户决定以编辑流畅性为优先，因此菜单、状态、缓存签名和所有障碍候选计算已经全部删除；普通连线可能经过卡片，但不再为此支付持续的大型树计算成本。
- “始终曲线”和“半透明卡片”是完成的探索性功能，不是已经证明更好用的默认功能。两者均可独立关闭并安全恢复原显示。
- 本轮没有未完成的正式项目，也没有需要用户手工补救的资源损坏。性能优化不属于本轮目标，未继续投入。
