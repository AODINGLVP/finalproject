1. 最终菜单

用户只需要判断“我现在是否需要这个显示效果”。节点创建仍在画布右键菜单中，排布、折叠和聚焦仍在 Layout 中，运行时信息仍在 Debug 中。
默认开启Smart Drag Reflow拖动距离足够大时，让碰撞节点实时让开。
默认开启Adaptive Zoom Detail按缩放自动改变卡片尺寸、信息量和间距。
默认关闭Readable Edge Overlay让连线透过卡片背景，但保护文字与端口。
默认开启Selection Context Highlight突出所选节点、祖先、直接子节点和兄弟。
默认开启Fisheye Focus放大指针附近节点并临时恢复完整信息。
菜单行为约定
勾选状态五项设置会保存；旧版设置首次升级时，新的 Adaptive 和 Selection 功能采用默认开启状态。
关闭功能立即清除该功能产生的临时视觉状态，保留行为树资源、节点参数、父子关系和执行顺序。
旧功能不再出现 Advanced Display 子菜单。仍有用途的实现被吸收到五项功能或后台保护中。

2. 五项功能的具体操作

1Smart Drag Reflow

默认开启
用户怎么操作直接按住节点拖动。单击或很小的修正不会启动排版；累计移动超过约 10 个屏幕像素后开始实时避让，之后每移动约 8 个屏幕像素刷新一次。
画面会发生什么被拖节点始终跟随指针；只移动与它发生碰撞的附近卡片。不会把整棵树强制排成统一的层级模板。
相对关系保护如果保存时父节点底部本来就在子节点顶部之上，避让后继续保持这个关系；原本平行、倒置或互相重叠的自由布局不会被强制改成上下层级。
关闭后拖动超过 10 像素也不会移动邻居。Adaptive Zoom 和 Fisheye 仍可在各自触发时独立使用同一套避让算法。
资源与历史只有用户实际拖动的节点在释放时保存新坐标并进入 Undo / Redo；邻居的避让位移只是显示状态，不写入资源。

2Adaptive Zoom Detail

默认开启
用户怎么操作正常使用滚轮缩放，不需要额外选择 Compact 或 Semantic Zoom。功能会根据当前缩放自动切换。
三个显示层级
低于 62%：紧凑卡片 + 核心信息62%–88%：普通卡片 + 中等信息88% 及以上：普通卡片 + 完整信息
自动布局卡片尺寸跨过阈值时立即重新检查重叠。视口锚点尽量保持观察中心，临时避让保持原有左右顺序和已经存在的父子高低关系。
关闭后所有卡片恢复普通尺寸和完整信息；滚轮仍会改变镜头缩放，但不会再按比例改变信息密度。
资源影响缩放层级、紧凑尺寸和避让位移都不写入行为树资源，不改变节点参数、结构或运行结果。

3Readable Edge Overlay

默认关闭
用户怎么操作当大型树的连线经常被卡片完全挡住时开启；不需要改变当前的直线连接方式。
画面会发生什么卡片背景变为约 72% 的原透明度，因此后方连线仍可辨认。标题、描述、类型、Decorator、失败原因和运行状态使用不透明文字与深色轮廓遮罩。
不会遮挡什么连线可以从卡片背景下方透出，但不会直接穿过可读文字；连接端口与重要状态色仍保持不透明。
与现有连线功能继续使用默认直线、单连接绘制、连线命中与右键断开。透明遮罩功能不改变线路端点、命中区域或连接结构。
关闭后恢复原主题背景、文字样式和几何尺寸，不留下透明度或文字轮廓覆盖。

4Selection Context Highlight

默认开启
用户怎么操作单击任意节点即可。附着的 Decorator 被选中时，会把关系高亮映射到它所属的画布卡片。
高亮范围
  • 选中节点：最强强调；
  • 从根到选中节点的祖先路径；
  • 选中节点的直接子节点；
  • 与选中节点同父的兄弟节点；
  • 其他节点适度淡化。
连线表现祖先路径、直接子连接和兄弟连接使用不同颜色与粗细。不会把选中节点的全部后代都点亮，以免大型树再次变成“几乎全图高亮”。
显示优先级Live Debug 活动路径优先于 Search；Search 优先于 Selection Context；选择高亮不会覆盖更重要的运行时或搜索状态。
关闭后立即恢复普通节点与连线样式，不显示额外 Breadcrumb 行，也不修改当前选择或行为树数据。

5Fisheye Focus

默认开启
用户怎么操作把指针移到节点上。焦点节点最多放大约 1.25 倍，周围卡片缩小到约 0.78 倍；滚轮缩放时暂时停用，指针再次移动后恢复。
信息变化即使画布处于最低 Adaptive 层级，焦点节点也会临时使用普通卡片几何并显示完整描述、Decorator 与状态信息；周围节点保持低密度。
实时布局焦点变化时立刻避让放大的卡片，保持无重叠、兄弟左右顺序以及原本成立的父子高低关系。
与拖动的关系单击节点不会反复重排。只有拖动超过 Smart Drag 的启动距离时才结束当前鱼眼状态并转交给拖动避让。
关闭或离开后清除焦点倍率和完整信息覆盖，恢复当前 Adaptive 层级。所有鱼眼位移均为临时显示，不写入资源。

共同的布局流程

STEP 1检测触发拖动、跨缩放阈值或改变鱼眼焦点。
STEP 2确定锚点固定被拖或被聚焦节点，减少无关移动。
STEP 3局部避让仅处理发生碰撞的卡片。
STEP 4保护顺序保留左右顺序和原本成立的上下关系。
STEP 5只显示结果临时位移不写入行为树资源。

4. 不再占用 Display 开关的能力

自动显示支持

搜索、概览小地图、运行时活动路径、非活动分支淡化、失败原因和 Decorator 条件提示继续按其原有入口工作。

连接与视口保护

默认直线、单连接绘制和缩放视口锚点作为基础实现持续工作，为五项功能提供稳定端点、命中和观察位置。

明确操作

Auto Arrange、概览排布、折叠/展开、分支聚焦、显示完整树和 Fit to View 继续放在 Layout；它们不是持续显示开关。

5. 最小验收方法

每次修改显示功能时，先检查以下五类结果。大型树只需要补做 241 节点最大缩放快速用例，不必每次运行全部压力测试。

菜单与复位Display 只有五项；开关顺序和默认状态正确；关闭后没有旧样式残留。
Adaptive 缩放在 61.9%、62%、87.9%、88% 和最大缩放检查尺寸、信息层、零重叠和资源坐标不变。
拖动死区9 屏幕像素不重排，超过 10 像素开始实时避让；关闭 Smart 后大范围拖动也不移动邻居。
选择与状态优先级验证选中、祖先、直接子节点、兄弟和相关连线；再叠加 Search 与 Live Debug 检查优先级。
鱼眼与连线可读性低缩放下焦点显示完整信息、周围保持紧凑；Readable Edge 开启时连线透过背景但不穿过文字。
行为树语义所有显示操作前后比较树结构、执行顺序和未拖动节点的保存坐标，结果必须一致。
