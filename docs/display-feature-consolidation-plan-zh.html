1. 已经确认的固定规则

这五项不再放回后面的决定列表。

“内建”不代表始终改变画面。 Search 只有输入非空查询才高亮；Active Path 和 Branch Dimming 只有 Live Debug 提供有效活动路径时才生效。没有查询、快照或活动路径时，画布保持普通状态。

内建Overview + Detail / Enhanced Minimap

画布右下角长期提供约 230×150 的全树概览，显示整棵可见树、当前视口位置和当前缩放所代表的细节程度。它帮助用户在大树中判断自己位于哪里。

不会做什么：不会修改节点坐标、折叠状态、父子结构或执行顺序。

默认开启；Display 和 Advanced Display 均不显示开关。

内建Search + Highlight

搜索栏始终可用，可匹配节点标题、类型、描述、Action/Condition 参数以及附着 Decorator。结果按钮可前后切换，提交查询可展开隐藏分支并取景目标。

复位方式：清空查询即清除匹配高亮和非匹配淡化，不需要再关闭“搜索功能”。

默认可用；保留搜索框，不显示能力开关。

内建Active Path Highlight

Live Debug 收到活动路径后，自动高亮从 Root 到当前运行叶节点的卡片和连接线，帮助解释 AI 当前走到了哪一个决策分支。

复位方式：Live Debug 关闭、快照清空或活动路径为空时自动取消，不修改行为树资源。

默认开启；不在 Display 或 Debug 中提供独立开关。

内建Non-active Branch Dimming

存在有效活动路径时，自动降低其他分支的视觉强调，让活动决策更容易识别。活动路径上的卡片保持完整不透明度。

安全条件：路径为空时绝不能把整棵树全部淡化；停止 Live Debug 后恢复所有分支。

默认开启；Debug 中不再显示 “Dim Inactive Branches”。

隐藏关闭Grid

Godot GraphEdit 的网格绘制代码仍然保留，便于内部测试或以后重新启用，但正常用户界面不提供 Grid 菜单项。

旧设置迁移：即使旧配置记录了 grid=true，新界面也以关闭状态启动，避免用户看到网格却无处关闭。

默认关闭；普通和高级菜单都不显示；没有删除内部实现。

4. 按关联关系理解功能

同组不代表必须绑定成同一个开关。

A. 卡片信息密度

Compact + Semantic Zoom + Decorator Badges。Compact 固定使用小卡片并压过语义层；Semantic Zoom 按缩放显示不同字段；Decorator Badges 只在完整详情层有意义。

可组合方向Full / Adaptive / Compact 三选一
保存影响只改显示，不改树资源

B. 局部查看与布局保护

Fisheye 是用户效果；Auto Spacing 与 Zoom Anchor 是支撑。点击不重排，小于约 10 个屏幕像素的微调允许少量遮挡，明显拖动才启动避让。

自动联动卡片放大后临时避让并维持视野
保存影响visual offset，不写节点坐标

C. 结构裁剪与导航

Collapse、Focus、Breadcrumb、Search、Minimap。Collapse 保存分支折叠状态；Focus 临时只看指定分支；Search 定位全树；Breadcrumb 表示选择路径；Minimap 提供全局方向。

不能强绑搜索不能静默折叠或聚焦整树
状态差异Collapse 保存，Focus/Search 临时

D. 节点识别

Type Encoding + Accessibility。前者增加形状和图标，后者使用色盲友好配色。当前 Ctrl+F、F3、Shift+F3 快捷键仍与 Accessibility 状态绑定。

候选模式Standard / Shape+Color / Accessible
待解决快捷键是否应永久可用

E. 连线显示

Single Connection 是自定义渲染基线。Default Channel、Straight、Orthogonal、Bundled、Curved 是路线风格，用户最终只应选择一种。

当前优先级Straight > Curved > Bundled > Orthogonal > Default
推荐改为互斥单选

F. 自动排布

Auto Arrange 会写入资源坐标和历史。Multi-column 与 Stable Layout 是它的策略；Dense Overview 是另一种保存排布。它们不能与只改临时偏移的 Auto Spacing 合并。

会写资源明确执行 Layout 命令时
不会写资源缩放、Fisheye、自动避让时

G. 运行解释

Live Debug 提供数据。Active Path 与 Branch Dimming 自动生效；Failure Reasons、Path Summary、Live Blackboard 和 Schema 面板保留不同用途。

自动反馈活动路径高亮 + 非活动分支淡化
可选信息失败原因、路径摘要、黑板面板

H. 实验与隐藏项

Translucent Cards降低卡片背景透明度但保护文字与描边；Curved是实验连线路线；Grid单独归为隐藏关闭，不再称为用户偏好。

不能合并Translucent 与运行分支淡化语义不同
Grid实现保留，界面无入口

6. 实施与兼容边界

精简菜单不能破坏已有树或让旧配置产生无入口状态。

旧配置

旧的四项 false 在正常界面中忽略，按内建开启处理；旧的 grid=true 忽略并固定关闭。兼容键仍可保存，便于旧版本读取。

内部实验

自动测试和论文基准仍可通过内部接口临时关闭 Minimap、Search、Active Path 或 Dimming，用于构造对照；该接口不暴露给普通用户。

树资源安全

菜单和默认状态迁移不得修改节点坐标、父子关系、左右执行顺序、Decorator 归属、保存路径或运行语义。

显示复位

Search 清空查询后复位；Live Debug 无路径或关闭后恢复强调；隐藏 Grid 始终关闭。只有明确 Layout 命令可以写入节点排布。
