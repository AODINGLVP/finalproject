\chapter{研究方法}
\label{ch:methodology}

\section{研究策略}

本研究采用设计科学与软件工程结合的策略。研究产物是 Godot 4.6 插件和可执行演示；研究知识来自把行为树语义和可视化文献中的设计要求落实为系统，再测量其正确性、显示属性和运行成本。迭代开发是必要的，因为编辑器集成暴露了单独算法中看不到的问题，例如坐标空间错误、残留 Transform、重复连线和半写入调试快照。

过程分为五个阶段：首先把导师会议要求和论文规范转化为验收门槛；其次建立最小可执行行为树核心和游戏集成；然后加入编辑操作和 Live Debug；随后将显示技术放在独立开关后，每次增加功能都测试关闭与复位；最后用确定性工作负载和分层测试比较完成系统与自身基线。后续任务完成后重新运行完整回归，以防图重建或资源复制改动破坏早期功能。

\section{实验因素与数据集}

三棵确定性生成树分别包含 31、121 和 364 个节点，代表易于编辑的小树、超过导师所提约 50 节点可读性边界的中型树，以及大型压力场景。三棵树使用相同生成规则，使规模成为主要差异；固定目标节点则保证搜索和实时路径截图可重复。

显示实验以完整细节节点--连线图为基线，主要条件为 Compact、Semantic Zoom、Search、Subtree Focus、Subtree Collapse、Fisheye 和 Enhanced Minimap。其余功能通过 19 项开关循环覆盖。指标定义如下：可见比例为可见节点数除以总数；卡片面积为可见卡片最小宽高乘积之和；信息字段表示当前语义层保留的代表字段；淡化节点数表示搜索或路径聚焦降低显著性的节点；鱼眼增益为目标卡片内部倍率；概览覆盖率为小地图表示节点数除以总数；操作时间为当前机器上的重建、更新或开关周期时间。

这些是界面仪器指标，不是心理指标。计划中的人体实验会另外记录任务完成时间、误选、缩放和平移次数、成功率，以及七点评分的可读性与认知负荷。

运行时实验交叉三种树规模、1/10/50 个 Runner 和缓存开/关。每个组合预热后测量七次。测试调整 Tick 数，使各条件执行一个有界且大致可比的总工作负载。使用 Tick 均值的中位数，以降低临时调度噪声影响；缓存和非缓存还必须返回相同终态。

\section{正确性与集成评估}

测试分为五个核心层。资源/运行时测试检查结构、节点语义、Decorator、Actor、Schema、调试快照和缓存失效；编辑器 GUI 测试实例化插件并检查创建、拖拽、连接、类型字段、保存重载、撤销重做和开关；基础游戏测试检查玩家与敌人交互；复杂竞技场测试覆盖索敌、追击、方向攻击、丢失目标、撤退与治疗；真实 GPU 回归在 1600×900 分辨率捕获 Godot Dummy 渲染器无法提供的可视属性。

判定策略严格：非零退出码、\texttt{FAIL:}、\texttt{ERROR:}、\texttt{SCRIPT ERROR:}、泄漏、资源未释放、非法访问或原生崩溃都会使套件失败。警告则按语义判断：故意调用不存在 Actor 方法是安全测试，应返回 \textsc{failure}；\texttt{--quit-after} 后的文件扫描中断属于预期关闭行为。

\section{视觉验证}

自动断言不能发现所有显示故障。因此视觉协议在 NVIDIA GeForce RTX 5070 Laptop GPU 和 Godot OpenGL 3.3 Compatibility 渲染器上生成稳定截图。核心截图覆盖基线、类型编码、灰度、无障碍配色、单线、紧凑、鱼眼开关、折叠、搜索、运行失败、实时黑板、Schema 编辑、Key 选择、正交连线、捆绑连线和复杂树；另外四张固定截图覆盖 121/364 节点概览、远距搜索目标和确定性 Live Debug 路径。

人工检查关注卡片重叠、端口位置、重复边、文字裁切、残留缩放、视口居中、活动路径连续性、淡化复位和小地图覆盖。正是该方法发现鱼眼虽然状态变量正确，却存在偏右中心和滚轮缩放干扰。

\section{人体实验设计}

计划采用被试内实验，对比 Baseline、Compact、Collapse、Fisheye、Search 和 Minimap。任务包括定位指定 Action、解释固定七节点运行路径、编辑指定 Decorator。条件使用平衡顺序，减少学习效应。工作簿支持 15 人、每人 18 次，共 270 行试验数据。

建议招募 8--15 名具备基础游戏或节点编辑经验的参与者，先完成统一训练。除匿名编号和可选经验类别外，不采集身份信息。正式招募前必须遵守学校伦理和导师要求。由于尚未实施，本文没有推断性人体实验结果。

\section{有效性与可复现性}

固定资源、确定性目标、独立开关、重复样本和集成后全回归增强了内部有效性。构念有效性仍受限制，因为面积和字段数是信息密度代理，不是可读性本身。外部有效性限于一台 Windows 笔记本、Godot 4.6、生成树和当前二维游戏。因此所有时间值都与硬件和工作负载一起报告，不视为跨设备常数。

复现材料包括原始 CSV、截图、测试脚本、公式工作簿、洁净安装打包脚本和 MIT 许可证插件包。人体实验材料与自动证据分开保存，防止未采集的数据被误认为结果。
